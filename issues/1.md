# 要件定義: bolt.newに依存しない形での再構築

このリポジトリは現在、bolt.newに依存していますが、依存しない形での再構築を検討する必要があります。以下にそのための要件を定義します：

## 要件定義

### 1. 基本機能
- **質問と選択肢のシャッフル**:
  - 現在の実装（React + JavaScript）を維持し、`useEffect`フックを利用してランダム化ロジックを実装する。
- **回答後の結果表示**:
  - 正解は緑色、間違いは赤色で表示するインジケータをReactコンポーネントで設計。
  - ダイアログではなく、画面内で非同期的に結果を表示。

### 2. 依存ライブラリの代替案
- **`bolt.new`の代替**:
  - `bolt.new`が提供している機能を特定し、その代替ライブラリまたはネイティブなJavaScript/Reactでの実装を検討。
  - 動的な質問データの読み込みについては、`import.meta.glob`をそのまま活用。

### 3. データ管理
- **JSONファイルの読み込み**:
  - クイズデータは引き続き個別のJSON形式で管理し、`fetch`や動的インポートを利用して読み込む。
  - ユーザーがJSONを貼り付けてクイズを生成できるよう、テキストエリアを提供。

### 4. 拡張機能（今後の実装を見据えた設計）
- **ChatGPTとの連携**:
  - OpenAI APIを利用して質問データを生成する機能を追加する。
  - これは将来的に設定パネルやモーダルで制御可能にする。

### 5. UI/UXの改善
- **モバイルフレンドリー**:
  - レスポンシブデザインを導入し、モバイルデバイスからも快適に利用できるようにする。

### 6. テストとデプロイ
- **テスト環境**:
  - Jestなどを利用してユニットテストを作成。
- **デプロイ**:
  - GitHub PagesやVercelを活用して、簡単にホスティングできる構成にする。

この要件に基づき、リポジトリの再構築を進めていくことを提案します。
